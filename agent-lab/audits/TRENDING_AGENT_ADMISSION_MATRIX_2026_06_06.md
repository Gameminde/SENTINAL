## Admission Doctrine

An admitted source is still untrusted. Admission authorizes only:

```text
source reading
architecture mapping
failure analysis
benchmark design
Sentinel-native rewrite proposals
```

Admission does not authorize:

```text
dependency installation
vendor runtime execution
account connection
credential use
vendor bridge creation
vendor code copying
```
