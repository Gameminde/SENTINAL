# Agent Lab Vendor Refresh Delta Report

Date: 2026-06-06

## Verdict

The April Agent Lab conclusions were directionally correct but materially
stale. The refreshed competitors did not merely add polish. They added durable
multi-agent workflows, proactive execution, real desktop surfaces, realtime
voice, stronger browser supervision, local/cloud strategy selection, workflow
engines, and much larger skill and channel ecosystems.

Sentinel still leads on provable authority, receipts, FinalGate, and explicit
memory-not-authority boundaries. It does not currently lead on total product
power.

## What Changed

### Hermes Agent

The old report described a capable agent with memory, skills, hooks, context
compression, and delegation. The refreshed source is closer to an agent
platform:

- the conversation loop, tool executor, guardrails, iteration budget, and
  system prompt are decomposed into explicit control points;
- persistent supervised CDP browser sessions were added;
- durable Kanban decomposition and adaptive execution intercepts were added;
- desktop, web dashboard, TUI, channels, voice, browser, code execution, LSP,
  MCP, credential pools, provider routing, and large skill bundles are present;
- promptware defenses now scan shared threat patterns and memory/tool-result
  boundaries.

Strongest harvest:

```text
durable task DAG plus intercept points
persistent supervised CDP lease
separated conversation/tool/guardrail control points
shared promptware scanner and tool-result delimiters
```

Reject:

```text
provider fallback as ambient product behavior
memory or skill text as implicit authority
unscoped credential pools
runtime skill execution without Sentinel admission
```

### OpenJarvis

OpenJarvis moved beyond hardware-aware routing:

- hybrid local/cloud agent strategies now compare worker pools, cost, latency,
  calls, and traces;
- `Conductor`, `Minions`, `ToolOrchestra`, and `SkillOrchestra` implement
  multi-agent and multi-model execution shapes;
- proactive agents, cron registration, persisted approval queues, research
  loops, and connector-driven proposals were added;
- spec-search learning, ACE optimization, and inter-framework benchmarks were
  added;
- hybrid search, embeddings, Gmail/Slack connectors, approval storage, and
  security regression fixes were added.

Strongest harvest:

```text
strategy selection from measured receipts
cost and energy as first-class routing signals
bounded recursive context inspection
proactive proposal queue with expiry
framework-comparison gauntlet
```

Reject:

```text
remembered always-approve
learned config mutation without review
direct remote skill import/run
trivial actions executing outside mission authority
```

### JARVIS

JARVIS's major addition is a real workflow operating layer:

- a versioned workflow IR, runtime, queue, triggers, sandbox API, engine pool,
  pieces catalog, editor, and execution monitor were added;
- OCR and screenshot capture moved into the device sidecar;
- realtime voice added semantic VAD, barge-in, session budgets, and direct
  navigation/action integration;
- OpenAI-compatible, Ollama, LiteLLM, and other providers expanded;
- filesystem containment, no-follow writes, secret permissions, and sidecar
  authentication were hardened.

Strongest harvest:

```text
versioned workflow IR and visual preview
content-addressed workflow artifacts
device-local visual capture
voice transport with interruption and budget
secure filesystem primitives
```

Reject:

```text
voice auto-approval of actions requiring approval
unknown tool fallback to a permissive class
community workflow pieces as trusted runtime code
child-process sandbox presented as strong isolation
```

### OpenClaw Official

The current official repository is no longer represented by the historical
Baseten snapshot. Verified upstream changes include:

- unified operator install policy;
- pinned commit acquisition for GitHub-backed skills;
- canonical turn serialization for stable sessions and replay;
- major continued work across channels, platforms, sessions, gateway, skills,
  and runtime durability.

The official source must receive its own specimen slot. The historical Baseten
snapshot remains valuable as a dated baseline and must not be silently
rewritten.

### Agent Zero

Agent Zero demonstrates unusually broad product power in one visible
workspace: a real Linux desktop, annotated browser, cowork documents,
subordinate agents, project isolation, scheduling, plugins, workspace history,
and a host connector.

Strongest harvest:

```text
operator-visible shared workspace
intervenable desktop/browser execution
project-scoped state and model presets
workspace time travel and scheduled tasks
```

Reject:

```text
ambient full-system authority
one-click community plugin trust
host connector access without narrow mission grants
```

### oh-my-pi

oh-my-pi shows that harness design itself can multiply model power. Its source
combines native/in-process tools, persistent Python and JavaScript kernels,
LSP and debugger operations, hash-anchored edits, interruption-time rules,
typed isolated subagents, background execution, and curated project memory.

Strongest harvest:

```text
content-addressed edit anchors
typed isolated worker results
interruption-time rule injection
native tool latency and output minimization
```

Reject:

```text
ambient shell and debugger authority
unreviewed inherited skills/rules
wide host execution without mission receipts
```

## Corrected Cross-Agent Lesson

The old synthesis assumed Sentinel should first build control and add execution
later. That sequencing succeeded: Sentinel now has real browser paths, a Power
Runtime, constrained shell/API/channel actuators, and an LLM live cockpit.

The new lesson is different:

```text
Control is no longer the bottleneck.
Durable useful execution is the bottleneck.
```

Future Agent Lab work should therefore measure:

```text
mission completion rate
time to useful result
long-horizon recovery rate
cost per completed mission
operator intervention count
real channel and desktop reach
memory usefulness across sessions
worker parallelism efficiency
```

Safety remains a release condition, not the primary product score.
