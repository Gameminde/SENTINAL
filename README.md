# Sentinel Control

Sentinel Control is a cognitive operating system for AI models.

The model remains the mind: reasoning, imagination, strategy, exploration and
judgment. Sentinel provides the governed digital body: state, memory, skills,
runtime, browser/computer organs, authority boundaries, receipts, replay,
cleanup and revocation.

```text
MODEL = reasoning / strategy / invention
SENTINEL = body / senses / runtime / proof / authority / laws
```

## Current Focus

Sentinel is being compressed into one canonical product spine:

```text
public request
-> RuntimeHost
-> RootMissionRuntime
-> ProductModelNativeDecisionClient
-> ExecutableCapabilityGraph
-> authority gate
-> ProductActionKernel
-> organ backend
-> receipt
-> CanonicalState
-> MissionProofRoot
-> cleanup / replay
```

The current branch is focused on the `SENTINEL_DEV_MAX_POWER_CANONICAL_CORE_V1`
campaign: one spine first, then each organ connected behind that spine.

## Doctrines

- Maximize model cognition inside granted mission scope.
- Keep real-world effects governed by explicit capability and authority.
- Treat semantic text as data, not authority.
- Keep receipts, replay, cleanup and kill/revocation stronger than the agent.
- Do not claim product success from local or deterministic tests alone.
- Preserve honest blockers instead of manufacturing success.
