## Why P6R5 Exists Before P6S

P6P selected Desktop Workspace L6 as the next real promotion because workspace
file operations are closest to limited production execution.

P6Q/P6R then proved a new constraint:

```text
Desktop is a context amplifier.
```

Desktop L6 will create file trees, diffs, write receipts, rollback refs, path
proofs, errors, retries, and future screenshot/clipboard state. If P6S dumps
that raw context into a model, Sentinel becomes expensive and confused.

Therefore:

```text
P6S may start only if it consumes P6R decision frames from the beginning.
```

## External Research Cross-Check

Anthropic's context-engineering framing supports Sentinel's direction: the
hard problem is selecting the right context configuration for the desired agent
behavior, not shoving the full state into every prompt.

LangGraph-style runtimes validate the graph/checkpoint direction: durable
state, persistence, replay, resume, and debugging matter once agents become
long-running.

OpenAI Agents SDK reinforces that tracing is not optional for serious agents:
model generations, tool calls, handoffs, guardrails, and custom events need
observable traces.

MemGPT supports Sentinel's operating-system analogy: context should be managed
as a hierarchy with retrieval and compaction rather than treated as one finite
prompt string.

Long Range Arena and Mamba support the cost warning: long-context systems need
serious efficiency evaluation. Subquadratic or linear mechanisms are useful
only if they preserve the content needed for decisions.

## Go / No-Go

```text
go_for_P6S = yes, conditional
```

Conditions:

```text
P6S must integrate P6R decision frames from the start.
P6S must never dump raw workspace trees/files/diffs into the LLM.
P6S must emit compact workspace state cards, diff summaries, receipt refs,
rollback refs, path containment proof, and authority cards.
P6S must keep exact artifacts outside the prompt and replayable by receipt.
P6S must remain Desktop Workspace L6 only, not full host control.
```

If P6S cannot satisfy those conditions, it should stop and harden P6R/P6Q
instead.
