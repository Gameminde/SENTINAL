## What Agent Lab Changes

### 1. Memory Must Be More Than A Vector Store

The next phase must combine:

```text
durable lexical and semantic retrieval
entity and relationship memory
contradiction/change tracking
expiry and revocation
receipt/evidence provenance
mission/user/entity separation
retrieval utility evaluation
poisoning and prompt-injection resistance
```

### 2. Replan Must Become A Durable Workflow

Sentinel already emits replan-ready packets. Competitor evidence shows that the
next power step is not another planner. It is a checkpointed runtime that can
turn a validated replan into a resumable branch while preserving authority and
proof.

### 3. Multi-Agent Power Must Follow Durability

Sentinel's advisory agent society is a strong contract seed, but real workers
should come only after workflow checkpoints, merge rules, and failure recovery
exist. Otherwise parallelism multiplies unfinished and contradictory state.

### 4. The Daemon Is An Operating Layer, Not The User Experience

The production daemon should be invisible infrastructure under cockpit,
channels, voice, and app surfaces. It must own leases, restart, scheduling,
pause, kill, and handoff. Triggers may propose work; only mission authority may
permit execution.

### 5. Harness Engineering Multiplies Every Model

oh-my-pi and gptme demonstrate that edit anchors, persistent mission-scoped
analysis kernels, typed isolated worker outputs, LSP/debugger evidence, and
small structured tool results can improve completion power without changing
the selected model or weakening authority.

### 6. Reach Should Expand After Continuity

Real channels, desktop, and voice are critical product-power layers. They
should follow memory, durable workflow, workers, daemon, skills, and routing so
that increased reach connects to a system that can recover and explain itself.
