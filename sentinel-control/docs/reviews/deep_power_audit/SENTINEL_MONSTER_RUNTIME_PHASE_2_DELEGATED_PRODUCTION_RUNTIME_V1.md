## Phase 2 Purpose

Prove that Sentinel can move from a mostly linear product loop into delegated production runtime:

```text
commander model
-> multiple meaningful reduced-authority workers
-> useful local product changes
-> semantic checks
-> bounded local channel
-> artifact export
-> offline verifier
-> replay no-respawn/no-reexecute/no-resend
```

The goal is not worker theater. A worker counts only if it produces a real worker receipt with reduced child authority and a distinct bounded role.
