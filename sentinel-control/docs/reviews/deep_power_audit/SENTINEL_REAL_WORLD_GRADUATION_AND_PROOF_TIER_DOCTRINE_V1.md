## Graduation Rules

1. Every implementation begins with local deterministic regression tests.
2. Every browser actuation or lifecycle change must graduate through a real
   Cloak body proof.
3. Every change involving model context, semantic understanding, strategy,
   recovery, completion, or open-world evidence must graduate through a real
   provider plus real Cloak mission.
4. `No provider call` is an isolation fact, not a product-quality achievement.
5. `LOCAL_CANDIDATE` must never be presented as final browser capability
   success.
6. A real-model mission evaluates objective satisfaction, not one exact
   trajectory.
7. If the model finds an unexpected safe path, the path is accepted and
   recorded when it satisfies the objective and authority constraints.
8. Non-holdout real missions are used for development and calibration. Frozen
   holdout tasks are not repeatedly consumed.
9. Every live mission must preserve provider decision events, runtime body
   facts, model blocker assessments, material receipts, continuity identities,
   FinalGate, cleanup/replay, and either a grounded terminal answer or truthful
   blocker.
10. Provider calls remain bounded, but real-model validation is mandatory
    before final capability claims.

## Cognitive OS Alignment

```text
MODEL = reasoning, strategy, exploration, interpretation
SENTINEL = body, senses, action runtime, evidence, authority, receipts, replay
```

Local proof protects implementation. Live body proof validates physical browser
capability. Real-model proof validates cognition and mind/body integration.
Holdout proof validates generalization.
