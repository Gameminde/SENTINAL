# Sentinel Model Amplification, Not Model Replacement Doctrine V1

Recorded at: 2026-07-13

## Canonical Verdict

```text
SENTINEL_MODEL_AMPLIFICATION_NOT_MODEL_REPLACEMENT_DOCTRINE_V1 = LOCKED
```

Sentinel must never attempt to replace the AI model's open-ended intelligence
with a closed rule-based controller.

Sentinel exists to expose, amplify, govern, remember, execute, and prove the
model's capabilities. It must not become a handcrafted intelligence ceiling.

## Canonical Identity

```text
MODEL =
reasoning
imagination
semantic understanding
strategy
exploration
judgment
invention
discovery

SENTINEL =
digital body
senses
world model
memory
skills and affordances
execution runtime
sandbox
evidence
authority
laws
receipts
replay
kill and revocation
```

The model remains the mind.

Sentinel is the governed body, sensory system, memory substrate, execution
runtime, proof layer, and law layer.

## Purpose

The purpose of Sentinel is to expose and amplify the model's unknown future
capabilities, not to restrict the model to strategies that Sentinel developers
can encode today.

Sentinel should make the model more capable by giving it:

```text
maximum perception
maximum governed capability
a fluid digital body
durable memory
experimentation space
evidence and replay
explicit real-world boundaries
```

Sentinel should not make the model weaker by forcing it into:

```text
fixed handcrafted plans
single exact action traces
closed ontologies
low-level runtime internals
browser locator thinking
preprogrammed semantic conclusions
planner trajectories that ignore model judgment
```

## Browser Cortex Consequences

The shared semantic classifier is:

```text
candidate generator
evidence producer
confidence producer
affordance hint
```

It is not:

```text
the final semantic judge
a fixed browser planner
a replacement for model reasoning
```

The classifier may tell the model:

```text
these controls may be search controls
these signals support that interpretation
these confidence levels were observed
these submission mechanisms appear available
```

The model remains free to interpret the page differently and choose another
safe strategy.

Typed search outcomes represent grounded environmental facts. They do not
dictate mission strategy.

The entity graph provides:

```text
evidence
relationships
contradictions
unknowns
confidence
possible interpretations
```

The model performs the higher-level reasoning, comparison, and interpretation.

Relevance machinery may provide constraint-level evidence and possible scores.
It must not become an inflexible rule engine that overrides model judgment.

The following remain model-led:

```text
query formulation
query refinement
research strategy
comparison strategy
exploration strategy
hypothesis selection
final answer usefulness judgment
```

## Reflexes Versus Cognition

Sentinel may automatically handle bounded mechanical recovery:

```text
stale reference
hidden control
ordinary timeout
detached element
page stabilization
fresh observation
safe ref rebuilding
backend session recapture
```

These are body reflexes. They are allowed below the model because they restore
the model's ability to act.

Sentinel must not silently take ownership of cognitive decisions:

```text
what the user truly means
which research strategy is best
how to reformulate the mission
which hypothesis to explore
what new tool should be invented
what constitutes the most useful final answer
```

Those remain model responsibilities.

## Open-World Architecture

Sentinel must not create closed ontologies that define everything it may ever
understand.

Schemas must remain extensible:

```text
unknown entity types allowed
new attributes allowed
new relationships allowed
model-proposed interpretations allowed
model-proposed SkillCandidates allowed in sandbox
```

A future model must be able to discover capabilities, workflows, and concepts
that were not anticipated by Sentinel's developers.

Sentinel may validate, sandbox, benchmark, govern, and receipt a new capability.
It must not reject it merely because it was not preprogrammed.

## Model Freedom Inside Authority

The model may choose any strategy that is:

```text
inside granted authority
inside mission scope
inside sandbox boundaries
evidence-producing
replayable where material
not crossing a real damage boundary
```

`recommended_next_skill` is advisory context, not a forced decision.

Sentinel may reject or block an action for:

```text
authority escape
safety boundary breach
secret or credential exposure
irreversible external effect outside authority
proof tampering
replay side effect
kill or revocation bypass
```

Sentinel must not reject an action simply because it differs from the expected
planner trajectory.

## Evaluation Doctrine

Future tests and corpora must evaluate:

```text
objective satisfaction
grounding
evidence quality
safety
authority compliance
recovery quality
efficiency
truthful uncertainty
```

They must not require one exact action sequence when multiple valid strategies
exist.

If the model finds an unexpected, safe, and effective path, that path must be
accepted and recorded as capability discovery.

Tests may require required proof properties:

```text
material receipts exist
replay has no side effects
hard boundaries hold
claims are grounded
unknowns remain unknown
```

Tests must not unnecessarily require:

```text
one exact search query
one exact browser control
one exact action order
one exact planner trace
one fixed ontology interpretation
```

## Application Scope

This doctrine applies to every future:

```text
Browser Cortex pack
Computer Cortex pack
Mission Studio pack
Self-Thinking and Skill Genesis pack
Physical and Industrial Cortex pack
worker orchestration pack
product action spine pack
quality corpus and evaluation pack
```

Any future pack that introduces classifiers, planners, score functions, schemas,
or recommendation engines must state explicitly whether that component is:

```text
advisory evidence
mechanical reflex
authority boundary
proof verifier
runtime executor
```

Only authority boundaries and proof verifiers may hard-stop. Advisory evidence
and mechanical reflexes must not become hidden cognitive governors.

## Final Doctrine

```text
Sentinel gives the model maximum perception.
Sentinel gives the model maximum governed capability.
Sentinel gives the model a fluid digital body.
Sentinel preserves proof and real-world boundaries.
The model remains the mind.
```
