## What Sentinel Must Avoid

```text
vendor runtime bridges
ambient shell or host authority
hidden fallback/AUTO
memory or skill text as authority
unscanned remote plugins
channel send without recipient-bound authority
desktop control without visible policy and kill
workflow triggers that create authority
```

## Competitive Conclusion

Sentinel leads on governed authority and proof. Competitors often feel more
powerful because they expose live tools, cohesive workspaces, real channels,
real desktop reach, and low-friction onboarding. The convergence program must
preserve Sentinel's control plane while closing those task-level product gaps.
