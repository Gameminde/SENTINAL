## Core Doctrine

Sentinel must not treat the LLM as a small JSON classifier, passive assistant,
or narrow decision widget. The LLM is the raw intelligence engine. Sentinel is
the body, memory, law, proof system, execution mediator, and certification
boundary around that intelligence.

```text
Maximum cognition.
Delegated execution.
Sovereign authority.
Certified action.
```

The central correction is:

```text
Sentinel is not proposal-only forever.
The future target is full LLM agency inside explicit delegated authority.
```

The LLM may dream without limits.
The LLM may act with delegated authority.
No raw thought becomes direct action.
The LLM may operate the body. The LLM may not rewrite the law of the body.

## What Sentinel Must Amplify

The LLM must be allowed to:

- imagine;
- reason;
- debate with itself;
- criticize its own ideas;
- generate multiple strategies;
- explore wild scenarios;
- research;
- code and plan code changes;
- synthesize evidence;
- anticipate risk;
- discover paths humans may not see.

Sentinel must give the LLM:

- living mission memory;
- evidence and receipts;
- browser, desktop, API, channel, file, OCR, vision, design, code, and future
  spend/trading organs under explicit authority;
- feedback loops from success, failure, rejection, and budget use;
- authority, risk, budget, receipt, and FinalGate boundaries.

## What Sentinel Must Never Confuse

Intelligence is not authority.

Model output may be:

- insight;
- strategy;
- plan;
- criticism;
- proposal;
- delegated operational choice;
- evidence interpretation;
- self-improvement recommendation.

Model output is not root permission. It cannot create, expand, or rewrite the
mission envelope, credential policy, provider/model contract, budget, risk
posture, or special authority contract.

## Canonical Future Terms

This docs pack standardizes these future terms before any code type is added:

- `RootAuthority`: sovereign permission from user mission, envelope, approvals,
  policy, and special authority contracts.
- `DelegatedOperationalAuthority`: bounded operational lane created by Sentinel
  gates inside Root Authority.
- `DelegatedActionLevel`: action ladder level from L0 thought-only through L7
  exceptional strategic action.
- `LLMRoleContract`: role-specific cognition, proposal, evidence, budget,
  receipt, validation, and downgrade contract.
- `ProposalArtifact`: structured non-executing output from cognition.
- `DelegatedActionCandidate`: proposed operation that can become a delegated
  lane only after gates pass.
- `GateDecision`: authority/budget/risk/organ verdict.
- `RoleLoopReceipt`: safe metadata receipt for role-loop cognition.
- `LivingMissionMemory`: safe mission memory built from evidence, receipts,
  traces, failures, rejected plans, successful strategies, open questions,
  uncertainty, and learned patterns.

## Living Intelligence Loop

Sentinel should make intelligence compound over time:

```text
memory -> reasoning -> delegated action -> receipt -> feedback -> better reasoning
```

Receipts become the LLM's memory of truth. Rejected actions teach boundaries.
Failed strategies become learning material. Good strategies become reusable
patterns. None of this grants new authority by itself.

## Boundary Sentence

```text
We do not make the LLM smaller to make it safe.
We make the authority boundary stronger so the LLM can become larger.
```
